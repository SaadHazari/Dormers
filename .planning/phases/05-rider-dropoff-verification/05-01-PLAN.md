**Exports:**

```typescript
export interface BoxCountResult {
  count: number | null       // null = could not count
  confidence: 'high' | 'medium' | 'low'
  reason: string
  imageQuality: 'clear' | 'unclear'
}

export async function verifyBoxCount(
  imageBytes: Uint8Array,
  mimeType: string,
  expectedCount: number,
): Promise<BoxCountResult>
```

**Implementation details:**

1. Import `generateText` from `'ai'` and `google` from `'@ai-sdk/google'`.

2. Use model `google('gemini-2.5-flash')` (NOT gemini-3.1-flash-lite -- Phase 5 needs higher multimodal accuracy for box counting).

3. Build the prompt via a local `buildBoxCountPrompt(expectedCount: number): string` function. The prompt must:
   - State "You are counting meal delivery boxes in a photo taken by a delivery rider."
   - Tell the expected count: "The rider says there should be N box(es) for this delivery stop."
   - Ask to count ALL visible boxes including partially hidden or stacked ones
   - Request JSON-only output with schema: `{ "count": number | null, "confidence": "high"|"medium"|"low", "reason": string, "imageQuality": "clear"|"unclear" }`
   - Instruct: return count null ONLY if image too dark, blurry, or obscured
   - Instruct: reason max 150 chars
   - End with: "Output JSON only. No explanation. No code fences."

4. Call `generateText` with a messages array containing one user message with two content parts: `{ type: 'text', text: prompt }` and `{ type: 'image', image: imageBytes, mediaType: mimeType }`. Set `abortSignal: AbortSignal.timeout(45_000)`.

5. On success, get `result.text.trim()`.

6. On error (catch block): log elapsed time, return a safe default `{ count: null, confidence: 'low', reason: 'timeout/unavailable message', imageQuality: 'unclear' }`. Check `elapsed >= 45_000` for timeout vs service error messaging.

7. Defensive parse (exact same pattern as `google-review-verify.ts`):
   - Strip ``` fences: `.replace(/^```(?:json)?\s*/i, '').replace(/```\s*$/i, '').trim()`
   - `JSON.parse(stripped)` in try/catch
   - On parse failure: return `{ count: null, confidence: 'low', reason: 'Could not parse verification result', imageQuality: 'unclear' }`

8. Normalise function `normaliseBoxCount(raw: unknown): BoxCountResult`:
   - `count`: if `typeof raw.count === 'number'` use it; if `typeof raw.count === 'string'` use `parseInt(raw.count, 10)`; else `null`. Check `Number.isFinite(count)` -- if not, set to `null`.
   - `confidence`: strict union check ('high' | 'medium' | 'low'), default 'low'
   - `reason`: if string, `.slice(0, 200)`, else 'No reason provided'
   - `imageQuality`: if `=== 'clear'` then 'clear', else 'unclear'

9. Add a console.log at the start: `[box-count-verify] calling Gemini (mime=${mimeType}, bytes=${imageBytes.byteLength})` and on response: `[box-count-verify] Gemini responded in ${elapsed}ms`.

This file must have ZERO imports from `@/infra/` -- it is a pure domain function per the layered architecture L1-BOUNDARIES rule. Only `ai` and `@ai-sdk/google` imports.

```typescript
export interface UpdateDeliveryPayload {
  deliveryDateIso: string

  tripNumber: number

  geminiConfidence: 'high' | 'medium' | 'low' | null
  photoPath: string | null
  verified: boolean
  geoLat: number | null
  geoLng: number | null
}

export interface UpdateDeliveryResult {
  ok: boolean
  rowsAffected: number
  error?: string
}

export async function updateDeliveryEvent(
  payload: UpdateDeliveryPayload,
): Promise<UpdateDeliveryResult>
```

**Implementation:**

1. Import `createAdminSupabaseClient` from `'@/infra/supabase/admin-client'`.

2. Create admin client: `const sb = createAdminSupabaseClient()`.

3. Build the update object:
```typescript
const updateData = {
  rider_count: payload.riderCount,
  gemini_count: payload.geminiCount,
  gemini_confidence: payload.geminiConfidence,
  photo_path: payload.photoPath,
  verified: payload.verified,
  confirmed_at: payload.verified ? new Date().toISOString() : null,
  geo_lat: payload.geoLat,
  geo_lng: payload.geoLng,
}
```

```typescript
const { data, error } = await sb
  .from('delivery_events')
  .update(updateData)
  .eq('delivery_date', payload.deliveryDateIso)
  .eq('dorm_name', payload.dormName)
  .eq('trip_number', payload.tripNumber)
  .select('id')
```

   - Otherwise: return `{ ok: true, rowsAffected: data.length }`
