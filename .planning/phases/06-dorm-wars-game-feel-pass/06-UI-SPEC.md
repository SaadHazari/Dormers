## Atmosphere Stack

Defines the visual layers stacked over the page from front to back (excluding modals).

| Layer | Z-index | Implementation | Spec |
|-------|---------|----------------|------|
| Modals (TitleScreen, RankUp, Welcome) | 10000+ | Existing pattern | Above all atmosphere — overlays cover grain & HUD during their moment |
| **Grain** (D-04 atmosphere) | 9999 | `position: fixed; pointer-events: none; inset: 0;` `<div>` with tiled noise | **Opacity 4–8%** (start at 6%, perf-tune in Wave 1). **24fps cycle** through 6–8 frames (12fps fallback if perf drops). Tile size 128×128px. Tile (not stretch). Implementation choice (SVG `<feTurbulence>` vs PNG noise tile) **Claude's Discretion** — Wave 1 perf test picks. **Must pass over anchor image too** (D-07 grain match). |
| HUD pod | 9000 | `position: fixed; top: 16px; right: 16px;` | Below modals, above page content |
| Edge alerts | 8500 | `position: fixed; top: 0; left: 0; right: 0;` | Below HUD pod so HUD remains readable during alert. Sits just below PulseTicker on its slide-in |
| Vignette | 8000 | `position: fixed; pointer-events: none; inset: 0;` radial gradient | Corners **12–15% darker** than NV center. Inner 60% of viewport stays unaffected. Gradient: `radial-gradient(ellipse at center, transparent 60%, rgba(0,0,0,0.13) 100%)` |
| Bloom emitters | per-element | `filter: blur(24px) saturate(1.4)` on duplicated absolute-positioned ghost element behind the source | See Hot Bloom Targets below |
| Page content (parallax layers) | 0–100 | `transform: translateY()` driven by scroll | See Parallax Stratification below |
| Anchor image (D-07) | -100 (background) | Behind hero content, partial composition ≤40% width | See Anchor Image Treatment below |

**Hot Bloom Targets — explicit list (only these elements get bloom):**
1. "war." headline (always-on bloom, audio-reactive intensity when audio enabled)
2. PulseTicker live dot (always-on bloom, subtle)
3. Cycle clock active arc (always-on, audio-reactive when enabled)
4. Rank pill orange border (always-on)
5. Daily Drop button border — **pre-claim state only** (post-claim green has no bloom)
6. Active Mission progress fill (always-on, audio-reactive)
7. HUD pod rank chevron during rank-change flash (transient — 200ms post-state-change)

**NOT bloom-eligible:** body text, secondary CTAs, copy-link button, leaderboard rows, ticker chip text, fine print, trophy tiles (any).

**Key-light direction:** **Top-left.** All highlight strokes and shadow asymmetry assume light source at upper-left. Drop shadows fall toward lower-right. Bloom is omnidirectional, not directional, so it doesn't conflict.

**CRT scanline overlay — scoped to HUD pod only:**
- Implementation: 1px-wide horizontal `repeating-linear-gradient(rgba(245,127,32,0.04) 0px, transparent 1px, transparent 2px)` overlay inside `HUDPod` only
- Subtle drift: `background-position-y` translates 0 → 2px over 8s linear infinite
- **Never overlays the rest of the page** — restricted to the HUD container's bounds via clipped child or `mask-image`
- Disabled by `prefers-reduced-motion: reduce` (drift pauses, lines stay static)

## Parallax Stratification

Stratified scroll parallax (D-09 `useStratifiedParallax.ts`). All layers move on the same scroll axis (Y); transforms applied via `requestAnimationFrame` driven from `window.scroll` listener with `passive: true`. Library choice: **hand-rolled rAF** (default per CONTEXT Claude's Discretion); planner may swap to `react-scroll-parallax` if it cleanly reduces module size.

| Layer | Multiplier | Elements |
|-------|------------|----------|
| Background | **0.5x** | Anchor war-room image (D-07) — moves slowest, sits "deepest" |
| Mid | **0.85x** | Hero radial-glow gradient, sub-headlines, SVG concentric-circles backdrop (lines ~675–682 of current DormWarsClient) |
| Foreground | **1.0x** | All block content (PulseTicker → FinePrint) — normal scroll |
| HUD pinned | **1.0x** (pinned via `position: fixed`) | HUD pod — never scrolls |

**Reduced-motion override (D-15):** All layers lock to 1.0x (no transforms applied). Scroll listener detaches.

**Perf budget:** Combined grain (24fps) + bloom (per-element) + parallax (rAF on scroll) must hold **≥60fps idle scroll, ≥30fps during rank-up cutscene** (per CONTEXT "Things to Watch"). Wave 1 perf-test step is mandatory before merging.

## Audio System

Three-stem ambient bed + ~8 stinger stems + ducking + spatial pan + audio-reactive bloom. **Audio default OFF** (D-16 supersedes Phase 5 D-29).

### ENABLE-AUDIO Pre-Prompt

| Element | Spec |
|---------|------|
| Position | Hero rank-pill row (same slot as Phase 5's `SoundToggle`) |
| Appearance (off state) | Pill: speaker-muted icon (Lucide → Wave 5 stencil) + "ENABLE AUDIO" text in 12px/600 cream. OG 1px border. NV2 surface. 32px height. Padding 4px 12px |
| Appearance (on state) | Same pill, icon flips to speaker-on, text flips to "AUDIO ON" cream, border stays OG. Tap toggles back to off |
| Persistence | `localStorage` key **`dw-audio-enabled`** (NEW — does NOT collide with Phase 5's `dw-sound`) — values: `"on"` / `"off"` (absent = off) |
| Activation effect | On enable: ambient bed crossfades in over 800ms. Stingers, ducking, spatial pan, audio-reactive bloom activate. ENABLE pill becomes the AUDIO ON pill |

### Three-Stem Ambient Bed

| Stem | Role | Volume (when bed plays alone) |
|------|------|-------------------------------|
| Drone | Low-frequency room tone — sustains presence | -18 dB |
| Comms chatter | Distant unintelligible radio chatter — adds activity | -24 dB |
| Duct hum | High-mid environmental hum — fills the spectrum | -22 dB |

All three loop seamlessly. Stored under `public/audio/dw/ambient/` (D-05). Format: `.mp3` + `.ogg` fallback. Loaded **only after** user enables audio (lazy-load, ~300KB total).

### Stinger Library (~8 stems)

Stored under `public/audio/dw/stingers/`. Format: `.mp3` + `.ogg` fallback. **Lazy-load on-demand per event** (not preloaded after ENABLE).

| Stinger | Event | Approx duration |
|---------|-------|-----------------|
| `unlock` | Mission ladder card unlocks | 600ms |
| `drop-reveal` | Daily Drop claim reveal | 800ms |
| `rank-up` | Rank-up cutscene | 1500ms (full cutscene length) |
| `warning` | Edge alert "INCOMING" trigger | 400ms |
| `copy-tick` | Copy-link button click | 80ms (same as Phase 5 `useSound` synth fallback) |
| `milestone-fanfare` | Conversion crosses chapter threshold | 1200ms |
| `conversion-impact` | Friend conversion event (with impact flash + microshake) | 300ms |
| `title-intro` | Title-screen interstitial 4s riser → impact → tail | 4000ms |

### Ducking

When any stinger plays, ambient bed **ducks by -6 dB** for the stinger duration + 200ms tail, then rises back over 240ms EXPO_OUT. Implemented via `GainNode` on the ambient bus.

### Spatial Pan

Spatial UI sounds use **`StereoPannerNode`**. Pan value maps to source element's horizontal viewport position: -1.0 (far left) → +1.0 (far right). Applied to: `copy-tick`, `unlock`, `drop-reveal`, `conversion-impact`. Center-anchored stingers (`rank-up`, `title-intro`, `milestone-fanfare`, `warning`) pan = 0.

### Audio-Reactive Bloom

`AnalyserNode` taps the master output. `getByteFrequencyData()` reads on `requestAnimationFrame`. Average mid-frequency amplitude (200–2000Hz band) → drives bloom-intensity multiplier (1.0 idle → 1.4 peak) on the Hot Bloom Targets list. Updates capped at 30fps to avoid jank.

**Reduced-motion (D-15):** Audio-reactive bloom **disabled** (bloom stays at static 1.0 intensity). Audio playback itself unaffected.

### Fallback Behavior

Until Wave 5 lands real stems, the system falls back to Phase 5's synth `useSound` for `copy-tick` and `milestone-fanfare`. Ambient bed silent until real stems integrated (D-03 architecture-first: system lands in Wave 2, stems land in Wave 5).

## Motion Craft — Impact Flash, Microshake, Chromatic Aberration, Cursor Reticle

### Impact Flash + Microshake (on friend conversion)

**Trigger:** Friend conversion event fires.

**Composition:**
1. **Impact flash** — full-viewport `rgba(245,127,32,0.18)` overlay, 80ms ease-out from 0.18 → 0 opacity
2. **Microshake** — page root container `translate(x, y)` random ±1.5px per frame for **120ms** at 60fps
3. **Audio** — `conversion-impact` stinger plays simultaneously (spatial pan based on recruit list row position)
4. **Edge alert** triggers in parallel (see above)

### Chromatic Aberration (on stinger events)

**Trigger:** Any stinger that plays *outside* the rank-up or title-intro cutscenes — specifically: `unlock`, `drop-reveal`, `warning`, `milestone-fanfare`, `conversion-impact`.

**Spec:**
- Implementation: duplicate target element layer + offset by `1–2px` on R channel and `-1px` on B channel using `filter: drop-shadow(1px 0 0 rgba(255,0,0,0.5)) drop-shadow(-1px 0 0 rgba(0,0,255,0.5))` OR canvas-based composite (Wave 4 perf test picks)
- Duration: **200ms ease-out** — splits in over 60ms, holds 40ms, recombines over 100ms
- Applied to: the source element of the stinger (e.g., the unlocking ladder card, the claimed Daily Drop card, the leaderboard row that dropped)
- **NOT applied** to the entire viewport — scoped to source element

**Reduced-motion (D-15):** Disabled. Element does not split. Stinger still plays.

### Cursor Reticle

**Spec:**
- Custom CSS cursor (via `cursor: url(...)` or canvas-rendered) — small stencil reticle (cross-hair with center dot, ~20×20px) in OG
- Applied to: all interactive surfaces (`button`, `a`, `[role="button"]`, the Daily Drop card, ladder cards, leaderboard rows, the HUD pod)
- Default cursor stays for body text, fine print, non-interactive surfaces
- Implementation: CSS-only via `cursor: url("data:image/svg+xml,...") 10 10, pointer;` (SVG inline data-URI keeps it asset-free)

**Reduced-motion (D-15):** Reverts to default `cursor: pointer` — no custom cursor swap.

## Anchor Image Treatment (D-07 — CRITICAL)

Single photographic anchor. **Mandatory treatment list** — failing any one of these breaks the perception flip the phase is paid for.

| Treatment | Spec |
|-----------|------|
| Source | Free stock — Unsplash or Pexels. War-room, tactical-map, or worn-paper-map photograph |
| **Duotone** | SVG `<feColorMatrix>` filter mapping: shadows → NV `#091825`, highlights → OG `#f57f20`. Alternative: CSS `filter: grayscale(1)` + `mix-blend-mode: overlay` on OG layer |
| **Grain match** | The page grain layer (Atmosphere Stack) passes over the image too. No separate grain on the image — it inherits the same grain layer that runs over the whole page |
| **Partial composition** | Image occupies **≤40%** of the hero section width. **Never full-bleed.** Never full-screen |
| **Edge feathering** | `mask-image: radial-gradient(ellipse at center, black 60%, transparent 100%)` OR `mask-image: linear-gradient(...)` to feather edges into NV background |
| **Vignette on corners** | Image's own corners darken further than the page vignette — local `radial-gradient` overlay or SVG vignette atop the duotone result |
| **Anchor placement** | **One specific moment only.** Options: behind the cycle clock in the hero, OR as a watermark in the Active Mission card. **Not multiple anchor uses across the page.** |
| **Parallax layer** | Background 0.5x (per Parallax Stratification) |

**If any of the above treatments is missing, the image MUST NOT ship.** Better to ship Phase 6 without the anchor image than to ship a untreated photo that breaks the war-room identity.

## Reduced Motion — Complete Construct Map (D-15)

**All new motion modules** must extend the existing `prefers-reduced-motion: reduce` block at line ~588 of `DormWarsClient.tsx`. Each module exports a `respectsReducedMotion: true` contract.

|------------------|---------------------------|
| Grain animation | **Pauses** (frame stays static at frame 0) |
| Stratified parallax | **All layers lock to 1.0x** — scroll listener detaches |
| Bloom (always-on) | Stays at static intensity (no audio-reactive variation) |
| Bloom (audio-reactive) | Disabled — bloom intensity stays at 1.0 |
| CRT scanline drift | Lines stay static (no `background-position` animation) |
| HUD pill expand/collapse | Instant snap (no 280ms tween) |
| NumberRoll | Jump-set (instant value swap, no per-digit tween) |

## Icon Set Visual Language (D-04 — Wave 5)

~15 Claude-authored stencil/military SVG icons, all sharing one design language.

| Property | Spec |
|----------|------|
| Stroke weight | **1.5px** uniform across the set. No mixed weights |
| Corner radius | **1px** on internal corners (subtle softness — not sharp military edges, not rounded UI icons) |
| Baseline alignment | All icons drawn on a 24×24 viewBox. Center the visual mass on the 12,12 axis |
| Optical compensation | Visually-thin shapes (e.g., a single chevron) draw slightly heavier than the 1.5px stroke (effective 1.8px) to optically match denser shapes |
| Fill philosophy | **Stroke-primary** (outline) — fills only where the stencil language requires (e.g., the inner blob of a flame, the dot inside a callsign) |
| Color | All icons accept `currentColor` so they inherit context — OG when active, CR when muted, etc. |
| Read at 12px | Must remain legible at 12px (HUD readouts) |
| Read at 48px | Must hold visual integrity at 48px (rank chevron expanded state, trophy tile icons) |

**Categories (15 icons total):**

| Category | Icons |
|----------|-------|
| Ranks (5) | Soldier, Sergeant, Commander, War Hero, Founder |
| Drops (5) | Credit, Multiplier, Skip, Spotlight, Intel |
| Mission rewards (3) | Free Skip, Free Week, Pause Unlocked |
| HUD (3) | Wallet, Flame, Callsign |
