# Phase 2 — UI Design Contract: Card Gallery

> Visual and interaction contract for the dish card gallery — replaces the 6 letter-button day selector with a horizontally scrollable image-forward card strip.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gap within card info section |
| sm | 8px | Padding inside card info section (horizontal) |
| peek | 12px | Peek of adjacent card at gallery edges — signals horizontal scrollability (exception: not a multiple of 4, declared explicitly for this purpose) |
| md | 16px | Gap between gallery cards |
| lg | 24px | Gallery strip top/bottom padding (matching existing `py-[24px]`) |
| xl | 32px | Reserved — not used in this phase |
| 2xl | 48px | Reserved — not used in this phase |
| 3xl | 64px | Reserved — not used in this phase |

Exceptions:
- Touch target minimum: 44px height on individual cards (ensures swipe hit area meets accessibility threshold)
- Card gap on mobile: 8px (sm) — tighter to allow peek of adjacent card
- 12px peek value: declared above as named token `peek` — not a multiple of 4, justified as the minimum pixel offset that renders a visually distinct sliver of the adjacent card without obscuring its content

## Card Dimensions

| Breakpoint | Card Width | Card Height | Photo Height | Info Height |
|------------|------------|-------------|--------------|-------------|
| Mobile (< 1024px) | 120px | 168px | ~101px (60%) | ~67px (40%) |
| Desktop (>= 1024px) | 140px | 196px | ~118px (60%) | ~78px (40%) |

- Card corner radius: `rounded-2xl` (16px) — matches existing dish image cards in Menu.tsx (line 1529)
- Gallery container: `overflow-hidden` with Framer Motion drag, no visible scrollbar
- Peek of next/prev card: 12px of adjacent card visible at gallery edges to signal scrollability

## Typography

| Role | Font | Size (mobile) | Size (desktop) | Weight | Line Height | Usage |
|------|------|---------------|----------------|--------|-------------|-------|
| Card day label | Montserrat | 10px | 12px | 700 | 100% | "Mon", "Tue", etc. above the dish name |
| Card dish name | Montserrat | 12px | 12px | 600 | 120% | Single line, truncated with `truncate` |
| Spice icon row | n/a (emoji) | 10px | 11px | n/a | 100% | Chilli emoji string, no custom font needed |

Weights in use: **700** (day label) and **600** (dish name) — exactly 2 weights. Body text outside the card (Poppins 300/400) is pre-existing and not re-declared by this phase.

Notes:
- Dish name on card is capped at 1 line with `overflow-hidden text-ellipsis whitespace-nowrap`. This matches CONTEXT.md D-02.
- Day label uses abbreviated 3-letter format ("Mon"–"Sat"), not the single-letter "M/T/W" of the old buttons. 3-letter is legible at 120px card width.
- Mobile type scale within the card: 10px (day label + spice row) / 12px (dish name) — a clean 2-step hierarchy at small card widths.

## Color

Theme-aware: the menu section already applies `bg-[#EEE9DA]` (light) / `bg-[#1E3A4F]` (dark) via `useTheme()`. Cards inherit this context.

| Role | Light theme value | Dark theme value | Usage |
|------|-------------------|------------------|-------|
| Dominant (60%) | `#EEE9DA` (cream) | `#1E3A4F` (navy) | Section background, card info section background |
| Secondary (30%) | `#1E3A4F` (navy) | `#EEE9DA` (cream) | Card photo placeholder background, selected card border |
| Accent (10%) | `#EEE9DA` (cream border) | `#EEE9DA` (cream border) | **Reserved for:** selected card border ring only |
| Unselected dim | `rgba(0,0,0,0.20)` overlay | `rgba(0,0,0,0.20)` overlay | Unselected card opacity treatment (~80% opacity) |
| Destructive | n/a | n/a | No destructive actions in this phase |

Accent (`#EEE9DA` cream border) is reserved for: **selected card border ring only**. It must not be applied to hover states, focus rings on unselected cards, or any other element in this phase.

Source: CONTEXT.md D-04, D-06; PROJECT.md brand colors.

## Selection Treatment

| State | Visual spec |
|-------|-------------|
| Selected card | `border-2 border-[#EEE9DA]` + `scale-105` via Framer Motion animate prop |
| Unselected card | No border + `opacity-80` (80%) |
| Transition | Framer Motion `layout` animation — scale + border fade over 200ms ease-out |

## Scroll / Drag Mechanics

| Property | Value | Rationale |
|----------|-------|-----------|
| Drag engine | Framer Motion `drag="x"` on gallery inner container | D-09: spring physics, not CSS overflow |
| `dragElastic` | `0.1` | Minimal bounce at drag boundaries — prevents cards flying off-screen |
| `dragTransition` | `{ bounceStiffness: 300, bounceDamping: 30 }` | Snappy deceleration, settles quickly on mobile |
| Snap-to-card on release | `onDragEnd` callback: compute nearest card index from final x offset, call `setSelectedDay` | D-10 |
| Auto-scroll to today on mount | `useEffect` on mount: animate gallery x to center the card matching initial `selectedDay` | D-11 / GALL-04 |
| Scrollbar | `scrollbar-hide` or `overflow-hidden` — no visible scrollbar | GALL-05 |
| Touch gesture conflict | Framer Motion drag with `dragDirectionLock` to prevent vertical scroll hijacking | GALL-05 smooth requirement |

Drag constraint computation:
- Gallery width = container ref width
- Inner track width = (cardWidth + cardGap) * 6
- `dragConstraints={{ left: -(innerTrackWidth - galleryWidth), right: 0 }}`

## Interaction States

| Trigger | Interaction |
|---------|-------------|
| Tap a card | `setSelectedDay(item.dayOfWeek)` — identical call to old letter buttons |
| Drag + release | Snap to nearest card, `setSelectedDay` for that card |
| Page load | Gallery animates to today's card (or first card if today is Sunday / no match) |
| No dish for selected day + filter | Show "No dish today" card placeholder (see Copywriting below) |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Day labels | "Mon", "Tue", "Wed", "Thu", "Fri", "Sat" — abbreviated, sentence-case |
| Spice: 1 chilli | "🌶" |
| Spice: 2 chilli | "🌶🌶" |
| Spice: 3 chilli | "🌶🌶🌶" |
| Empty state heading (no dish) | "Not available" |
| Empty state body | "No dish for this day" |
| Empty state (no match for veg filter) | "No veg option today" |
| Error state (image load fails) | Show cream background placeholder — no error text on card (image failure is silent; the card shape is preserved) |
| Destructive confirmation | None — no destructive actions in this phase |

Notes:
- No CTA button exists on the gallery cards — tapping the card IS the interaction. No button label needed.
- Allergen icons are intentionally absent from gallery cards (CONTEXT.md D-08). Allergen copy is deferred to Phase 3.

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Keyboard navigation | Each card is a `<button>` with `onClick={() => setSelectedDay(item.dayOfWeek)}` — tab-focusable |
| ARIA label | `aria-label="{day} — {dishName}"` on each card button |
| ARIA current | `aria-current="true"` on the selected card button |
| Drag affordance | Drag is a progressive enhancement — tapping cards is the primary interaction, drag is secondary |
| Minimum touch target | Card height 168px on mobile exceeds 44px minimum — no extra padding needed |

## Image Sizing

Gallery card images use their own `sizes` attribute (different from the main dish display):

```tsx
<Image
  src={dish.image}
  alt={dish.name}
  fill
  sizes="120px"
  className="object-cover"
/>
```

- 120px on mobile, 140px on desktop — both within the same media query breakpoint so a single `sizes="140px"` is acceptable as a conservative value.
- Source: Phase 1 established `sizes` pattern; gallery cards are narrower than the main dish display (140px vs 336px).
