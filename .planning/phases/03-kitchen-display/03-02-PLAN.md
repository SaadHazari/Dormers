   - Veg/Non-veg badge: same pill style as dish cards

3. **Tab bar (sticky, below header):** `position: 'sticky'`, stays below header, `backgroundColor: BG_DEEP`
   - Three tabs: "Ingredients", "Method", "Notes"
   - Active tab: bottom border `3px solid` in dish color (emerald or orange), `fontWeight: 700`
   - Inactive tabs: `opacity: 0.5`, no bottom border
   - Each tab: `padding: '12px 0'`, `fontSize: '16px'`, tap target spanning full width (flex: 1)
   - State: `const [activeTab, setActiveTab] = useState<'ingredients' | 'method' | 'notes'>('ingredients')`
   - Reset `activeTab` to `'ingredients'` when `activeRecipe` changes

4. **Tab content (scrollable):** `overflowY: 'auto'`, `padding: '20px 16px'`, fills remaining height

   **Ingredients tab** (`activeTab === 'ingredients'`):
   - Map over `recipe.sections` — each section has a `heading` and `items[]`
   - Section heading: `fontSize: '18px'`, `fontWeight: 700`, `color: CREAM`, `marginTop: '20px'` (0 for first), `marginBottom: '12px'`
   - Each item: `fontSize: '16px'`, `color: CREAM`, `opacity: 0.85`, `padding: '6px 0'`, `borderBottom: '1px solid rgba(237,232,218,0.06)'`

   **Method tab** (`activeTab === 'method'`):
   - Map over `recipe.method` — each is a step string
   - Numbered steps: `fontSize: '16px'`, `lineHeight: 1.6`, `color: CREAM`
   - Step number: inline bold circle or just bold number, `fontWeight: 700`, color matching dish type
   - `marginBottom: '16px'` between steps

   - Render `recipe.notes` as a paragraph
   - `fontSize: '16px'`, `lineHeight: 1.6`, `color: CREAM`, `opacity: 0.85`

- Empty sections array: Show "No ingredients listed" placeholder.
- Empty method array: Show "No method listed" placeholder.

**IMPORTANT:** All styles are inline. No Tailwind, no styled-jsx. Font sizes for recipe content 16px+ (above the 18px body text floor, recipe content can be 16px since it's dense reading — but section headings must be 18px+).
